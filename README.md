## 👨‍💻 About Me

I'm a hands‑on developer based in Finland, focused on practical systems, tooling, and AI‑assisted workflows. I like building end‑to‑end: from low‑level C++ utilities and networking code to Python scripts and full‑stack web apps.

- **Core:** C++ (systems, networking, performance), Python (automation, data, AI), TypeScript/React (web UIs)
- **Interests:** Local LLMs, security tooling, developer productivity, and small SaaS‑style products
- **Style:** Minimal, native, and fast — Windows‑first, but portable where it makes sense
